How to use XPedia

XPedia is a reference for OpenXcom / OXCE modpacks. There are four ways to use it; they all read the same files and produce the same pages.

In your browser

Drop a modpack archive — zip, rar or tar.gz — anywhere on this page (or click the + tile and choose the file). Loading takes a moment; the page then shows that pack. Click a pack tile to switch between packs, × to delete one. Note some packs in this list didn't come from a file (they are the pedia itself, or one served by the command line tool), so they have no delete button.

Use the search box or the section/category lists to find articles; the < / > arrows step through them. The language can be switched from the top menu. Everything is stored in your browser — nothing is uploaded anywhere.

Exporting a standalone page

The Export button makes a page that works without XPedia: either one HTML file, or a zip. By default images are read from your OpenXcom installation, so open the file from the game root for pictures to appear; tick Also keep the images to bundle them in (the file gets much larger). Audio is never bundled — only referenced.

Exports are always minified, whatever the page you exported from.

From the command line (xpedia-cli)

node xpedia-cli.mjs --help                               # documentation

node xpedia-cli.mjs pack.zip out                         # export to a folder (. to use current folder as source or target)
node xpedia-cli.mjs pack.zip out --assets                # bundle images
node xpedia-cli.mjs pack.zip out --lang ru,en-US         # export only ru and en-US 
node xpedia-cli.mjs pack.zip out --split                 # languages are exported as separate js files, loaded only when necessary
node xpedia-cli.mjs pack.zip out.zip --zip               # single zip archive
node xpedia-cli.mjs pack pedia.zip --zip                 # folder / rar / tar.gz  sources work too

A folder may be a game root (user/mods/…), a folder of mod folders, or one mod folder. --split keeps the page English-sized and writes other languages as separate files that load on demand. --url https://…/ adds link-preview tags for that address.

Live preview (xpedia-cli --serve)

node xpedia-cli.mjs --serve                          # current folder, port 9391
node xpedia-cli.mjs --serve "D:/OpenXcom/user/mods/MyMod"

Serves the folder as a live pedia: edit a ruleset file, reload the page, see the change — no repacking. Exporting from that page is handled by the same process, so the result still gets the images. GET /xpedia-export on the same port builds an export over HTTP.

Details & rules

What a pack needs to be understood: which file types are read (rulesets, languages, images, globe data), which are ignored (sounds), and how mod folders are recognised — these are the same rules in every mode.
