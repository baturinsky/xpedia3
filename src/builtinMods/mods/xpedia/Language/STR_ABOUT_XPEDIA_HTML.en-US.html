XPedia ${xpediaVersion}

XPedia is a wiki reference for the OpenXCom mods and modpacks. It harvests the data from the modpacks themselves, all you need is to provide it with the modpack itself.

Features

  • Entire modpack ruleset data, displayed in human-readable and searchable way.
  • HTML, node.js and exe versions.
  • Reads packs in Zip,Rar and Tar.gz archives.
  • In command line version - also accept directories and OpenXCom installations.
  • Very flexible export function to create xpedia versions with inlined mod data, to bundle with your mod or publish in the web.
Project canonical home, best place to give feedback is through "Issues" there: https://github.com/baturinsky/xpedia3
Live online versions for Xcom Files and X-Piratez: https://baturinsky.gitlab.io/xpedia

How to use XPedia

In your browser

Drop a modpack archive — zip, rar or tar.gz — anywhere on the page (or click the + tile on the landing page and choose the file). Loading takes a moment; the page then shows that pack. Click a pack tile or use the right drop down menu to switch between packs, × to delete one.

Use the search box or the section/category lists to find articles; the < / > arrows step through them. The language can be switched from the top menu. Pack data is stored in your browser — nothing is uploaded anywhere. Packs are set to automatically delete from the disk after a year of inactivity, but it cannot work on non-Chrome/Edge browsers.

Exporting a standalone page

The Export button makes a page that works without need for the modpack archive, either one HTML file, or a zip. By default, the images in the exported version are read from your OpenXcom installation, assuming that the HTML file is located in its root directory. Tick Also keep the images to bundle them in (the file gets much larger). Audio is never bundled — only referenced.

From the command line (xpedia-cli)

There are two CLI versions, with only difference that one is node.js script (and therefore needs node installed), and the other is exe (i.e. needs windows and much bigger). If you use the exe version, replace node `xpedia-cli.mjs` with `xpedia-cli.exe` 
node xpedia-cli.mjs --help                               # documentation

node xpedia-cli.mjs pack.zip out                         # export to a folder (. to use current folder as source or target)
node xpedia-cli.mjs pack.zip out --assets                # bundle images
node xpedia-cli.mjs pack.zip out --lang ru,en-US         # export only ru and en-US 
node xpedia-cli.mjs pack.zip out --split                 # languages are exported as separate js files, loaded only when necessary
node xpedia-cli.mjs pack.zip out.zip --zip               # single zip archive
node xpedia-cli.mjs pack pedia.zip --zip                 # folder / rar / tar.gz  sources work too

A folder may be a game root (user/mods/…), a folder of mod folders, or one mod folder. --split keeps the page English-sized and writes the other languages as separate files that load on demand.

Live preview (xpedia-cli --serve)

node xpedia-cli.mjs --serve                                # current folder, port 9391
node xpedia-cli.mjs --serve "D:/OpenXcom" --port 1234      # Serve all active mods in the installation on port 1234
node xpedia-cli.mjs --serve "D:/OpenXcom/user/mods/MyMod"  # Serve specific mod

CLI version serves the folder as a live pedia: you can edit a ruleset file, reload the page, and see the change nearly immediately.
